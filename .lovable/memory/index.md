## Core
Para a EXT5 (Instagram) a geração de imagem/legenda/vídeo usa o Lovable AI Gateway (LOVABLE_API_KEY) — o usuário confirmou que é o mesmo saldo de créditos do workspace/prompt. Para as outras extensões, IAs escolhidas na aba IAs continuam usando as contas próprias do usuário (não gastar Gateway sem pedido explícito).
Copy do Instagram (endpoint /api/public/instagram-generate) deve entregar: título magnético (máx 70 chars, 1-2 emojis, gancho forte), legenda profissional mín. 900 chars com muitos emojis coloridos, bullets ✅/➡️, DUAS chamadas explícitas para SEGUIR a página (uma no meio, uma no fim), 18-25 hashtags PT-BR, e para Reel roteiro de 5-7 cenas + voiceover PT-BR sincronizado. Imagem gerada em qualidade máxima (google/gemini-3-pro-image, 8K, cinematográfica, sem texto/logo).
